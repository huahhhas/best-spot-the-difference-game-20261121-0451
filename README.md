**Spot the Difference** — an original spot-the-difference game drawn entirely in
code. Two near-identical pictures side by side; find every change. Three
hand-drawn scenes: **Harbour at Dawn** (5 differences), **Night Market** (7)
and **Clockmaker's Workshop** (10). Click a difference to ring it, use hints
(H), beat the clock — wrong clicks cost 5 seconds. Vanilla JavaScript and
canvas 2D, no libraries, no network, plays offline in a desktop browser.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080 in a desktop browser
```

Screenshot states: `?shot=cover` (mid-game, 3 found), `?shot=title`,
`?shot=complete`, `?shot=win`, `?shot=hard`.
